# Datendetektei – Roadmap der Umsetzung

**Spec:** `docs/superpowers/specs/2026-10-12-datendetektei-design.md` (Abschnitt 16 „Phasen“).
Die Spec umfasst mehrere unabhängige Teilsysteme. Deshalb gibt es **einen Plan je Phase**. Der Plan für Phase 1 liegt
vor (`2026-10-12-phase1-geruest-kern.md`), der Plan für Phase 2 als Entwurf (`2026-10-12-phase2-sql-engine.md`). **Vor Beginn jeder weiteren Phase** erstellt Claude Code mit
`superpowers:writing-plans` den Phasenplan aus Spec + den unten genannten Quellen, legt ihn Frank zur Durchsicht vor und
arbeitet ihn dann ab (empfohlen: `superpowers:subagent-driven-development`).

Arbeitsweise in jeder Phase: Feature-Branch `phase<N>/<thema>` · TDD · `npm test` (+ `npm run validate` ab Phase 2) grün
· PR nach `main` erst nach Freigabe · Abnahmekriterium der Phase nachgewiesen (Testausgabe, Screenshots, Protokoll).
